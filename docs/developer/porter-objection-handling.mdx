# Porter objection handling

`api.porter.objections` classifies common Porter sales objections and returns
safe deterministic responses.

Covered objections:

- Not interested
- Call me later
- Send me information
- Already have funding
- Rates
- Funding speed
- Is this a loan
- Is this factoring
- Who are you
- How did you get my number
- Can you email me
- Angry response
- Gatekeeper
- Voicemail

The handler does not send email, leave production voicemail, disclose sensitive
lead data to gatekeepers, quote rates, promise approval, or guarantee funding.
